ST SINGTO STORE — n8n Clipboard Paste Pack

วิธีใช้:
1. เปิดไฟล์ *_PASTE.json หรือ *_PASTE.json ในตัวอ่านไฟล์แบบ Plain Text
2. กด Ctrl+A แล้ว Ctrl+C ให้ครบทั้งไฟล์
3. ใน n8n เปิดเมนูสามจุด > Import from Clipboard
4. วางด้วย Ctrl+V
5. ตรวจเส้น connections ใน canvas ก่อนกดใช้งาน

ไฟล์เหล่านี้เป็น n8n export JSON แบบ minified เพื่อให้ก๊อปทั้งก้อนได้ง่ายขึ้น
มี nodes และ connections ครบตาม workflow ต้นฉบับ ไม่ใช่ไฟล์ Code node รายตัว
