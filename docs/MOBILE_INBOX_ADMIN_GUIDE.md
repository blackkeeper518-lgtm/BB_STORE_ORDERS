# คู่มือแอดมิน: ติดตั้ง ST SINGTO STORE Mobile Inbox เป็นแอป

## ใช้ทำอะไร

ST SINGTO STORE Mobile Inbox เป็นเว็บแอปสำหรับรวมแชทแอดมินไว้ในหน้าจอมือถือ สามารถอ่านห้องแชท ตอบข้อความ ส่งภาพ และเลือกเพจได้ โดยไม่ต้องติดตั้งจาก Play Store หรือ App Store

ก่อนติดตั้ง ให้เปิดลิงก์ Mobile Inbox ที่ผู้ดูแลระบบส่งให้ และตรวจว่าหน้าจอแสดงคำว่า **กล่องข้อความ** ของ ST SINGTO STORE แล้ว

## Android: Chrome

1. เปิดลิงก์ Mobile Inbox ด้วย **Google Chrome**
2. รอให้หน้าแชทโหลดครบ
3. ถ้ามีปุ่ม **ติดตั้งแอป** บนแถบด้านบน ให้กดปุ่มนั้น
4. กด **ติดตั้ง** หรือ **Install** ในหน้าต่างยืนยัน
5. กลับไปที่หน้าจอหลัก แล้วเปิดไอคอน **ST SINGTO STORE Inbox**

ถ้าไม่เห็นปุ่มติดตั้ง:

1. กดเมนูจุดสามจุด `⋮` มุมขวาบนของ Chrome
2. เลือก **ติดตั้งแอป** หรือ **เพิ่มไปยังหน้าจอหลัก**
3. กดยืนยันการติดตั้ง

## iPhone / iPad: Safari

1. เปิดลิงก์ Mobile Inbox ด้วย **Safari** เท่านั้น
2. กดปุ่ม Share รูปสี่เหลี่ยมมีลูกศรขึ้น
3. เลื่อนเมนูแล้วเลือก **เพิ่มไปยังหน้าจอโฮม**
4. ตรวจชื่อ **ST SINGTO STORE Inbox**
5. กด **เพิ่ม**
6. เปิดแอปจากไอคอนบนหน้าจอหลัก

บน iPhone ไม่ควรติดตั้งผ่าน Chrome เพราะคำสั่งเพิ่มไปยังหน้าจอโฮมต้องทำผ่าน Safari

## คอมพิวเตอร์: Chrome หรือ Edge

1. เปิดลิงก์ Mobile Inbox
2. ดูที่แถบที่อยู่ด้านขวา หากมีไอคอนติดตั้ง ให้กดไอคอนนั้น
3. กด **Install**
4. เปิดแอปจาก Desktop, Start Menu หรือเมนู Apps

ถ้าไม่เห็นไอคอน ให้เปิดเมนูเบราว์เซอร์แล้วเลือก **ติดตั้ง ST SINGTO STORE Inbox** หรือ **บันทึกและแชร์ → ติดตั้งหน้าเป็นแอป** ตามชื่อเมนูของเบราว์เซอร์

## การใช้งานหลังติดตั้ง

- เลือกเพจจากช่อง **เลือกเพจ**
- แตะห้องแชทเพื่อเปิดเต็มจอ
- แตะปุ่มย้อนกลับในหัวห้องเพื่อกลับไปหน้ารวมเพจและห้องแชท
- พิมพ์ข้อความแล้วกดปุ่มส่ง
- แนบภาพได้สูงสุด 4 ภาพต่อข้อความ
- สามารถวางภาพจาก Clipboard ในช่องข้อความได้
- ปุ่มรีเฟรชใช้ดึงข้อมูลแชทล่าสุด
- ปุ่มธีมใช้เปลี่ยนสีหน้าจอมือถือ

## การตั้งค่า Token สำหรับแอดมิน

แอดมินไม่ต้องกรอก Meta Page Access Token, Chat service-role key หรือ Token ลับใด ๆ ในโทรศัพท์ ระบบจะอ่านค่าการเชื่อมต่อ Chat จากฝั่งเซิร์ฟเวอร์/Render ที่ผู้ดูแลระบบตั้งไว้แล้ว หากแอปแจ้งให้ตั้งค่า Token ให้แจ้งผู้ดูแลระบบ ไม่ควรนำ Token ไปกรอกหรือส่งในแชท

## ถ้าแอปไม่โหลดข้อมูล

1. ตรวจว่าโทรศัพท์ต่ออินเทอร์เน็ต
2. ปิดแอปแล้วเปิดใหม่
3. ตรวจว่าเปิดลิงก์ที่ถูกต้องและไม่ได้อยู่ในโหมดไม่ระบุตัวตน
4. ถ้ายังไม่พบแชท ให้แจ้งผู้ดูแลระบบพร้อมภาพหน้าจอและเวลาที่พบปัญหา

## ถ้าแอปส่งข้อความไม่ได้

อย่ากดส่งซ้ำหลายครั้ง ให้ตรวจว่าข้อความยังอยู่ในช่องพิมพ์หรือไม่ แล้วแจ้งผู้ดูแลระบบพร้อมข้อมูลห้อง เพจ และเวลาที่ส่ง ระบบอาจกำลังรอการตอบกลับจาก Meta

## เรื่องรูปโปรไฟล์ลูกค้า

รูปโปรไฟล์เป็นข้อมูลที่ระบบจะจัดการจากข้อมูลจริงของ Meta เท่านั้น ถ้า Meta ไม่คืนรูป ระบบจะแสดงอักษรแรกของ `facebook_name` แทน ห้ามแอดมินอัปโหลดหรือเปลี่ยนรูปแทนลูกค้าเอง

## การอัปเดตแอป

ไม่ต้องติดตั้งใหม่ทุกครั้ง เมื่อระบบมีการอัปเดต ให้ปิดแล้วเปิดแอปใหม่ หรือรีเฟรชหน้า หากยังเห็นหน้าจอเก่า ให้ปิดแอปจากรายการแอปล่าสุดแล้วเปิดใหม่อีกครั้ง

## ข้อควรระวัง

- ห้ามส่ง Page Access Token หรือภาพหน้าจอที่มี Token ให้ผู้อื่น
- ห้ามเปิดลิงก์ระบบผ่านเครื่องสาธารณะ
- ห้ามล้างข้อมูลเว็บไซต์หรือถอนการติดตั้งโดยไม่แจ้งผู้ดูแลระบบ หากยังต้องใช้งานห้องแชทเดิม
