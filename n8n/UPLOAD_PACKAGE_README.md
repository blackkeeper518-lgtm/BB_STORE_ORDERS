# Drakside full update package

แพ็กเกจนี้รวมไฟล์อัปเดตทั้งหมดตั้งแต่ origin/main จนถึงเวอร์ชันล่าสุด รวมการแก้จอเต็ม, Product Alien, ช่องเสียบ Telegram และการลดสี bubble ข้อความเพจ

ให้นำไฟล์ทุกไฟล์ไปวางทับตาม path เดิมของรีโพซิทอรี ห้ามเปลี่ยนโครงสร้างโฟลเดอร์

ไฟล์ล่าสุดที่สำคัญคือ `client/src/pages/ChatHub.tsx` ซึ่งแก้สี bubble ฝั่งเพจให้เข้มลงและอ่านง่ายขึ้น
